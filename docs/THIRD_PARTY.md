# Использованные материалы

- **Leaflet** — библиотека интерактивной карты. Поставляется в `dashboard/vendor/leaflet/` по лицензии BSD-2-Clause; полный текст и copyright сохранены в [LICENSE](../dashboard/vendor/leaflet/LICENSE).
- **OpenStreetMap** — подложка карты и данные участников проекта. Атрибуция `© OpenStreetMap contributors` сохранена на карте. [Авторские права и лицензия данных](https://www.openstreetmap.org/copyright), [правила использования тайлов](https://operations.osmfoundation.org/policies/tiles/).
- **Дорожная геометрия Ирины** — локальный кеш [OSRM](https://project-osrm.org/) через плановые остановки из версии `irina` команды, коммит `a806989`, `irina/dashboard/data/route-network.json`. Упакован в [dashboard/assets/road-network.json](../dashboard/assets/road-network.json) инструментом `tools/prepare_route_geometry.py`; хеш исходника сохранён внутри. Данные дорог — © OpenStreetMap contributors, [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Кеш используется только для рисунка карты, не содержит GPS и не влияет на прогнозы. Это расчёт автомобильного пути, а не подтверждённая трасса автобуса; неизвестные пары остановок соединяются схематично. Обращений к OSRM во время работы дашборда нет.
- **opentransportdata.swiss** — источник швейцарских данных, использованных командой при обучении Transformer: [Actual data, выпуск 24.09.2026](https://data.opentransportdata.swiss/en/dataset/ist-daten-v2). Использование регулируется [условиями источника](https://opentransportdata.swiss/en/terms-of-use/). Исходный швейцарский датасет в репозиторий не включён.

Из раздачи организаторов включены пять CSV для воспроизведения: `dataset/train/{traffic.csv,schedule.csv}` и `dataset/validate/{traffic.csv,schedule_plan.csv,points.csv}`. Официальный образ эмулятора в репозиторий не включён.
