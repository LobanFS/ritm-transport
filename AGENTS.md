# Работа с проектом

Работать в main. Сначала читать README.md и docs/JURY.md. Поддерживать короткие инструкции запуска; результаты измерений не заменять предположениями.

В Git разрешена поставка пяти CSV из раздачи: `dataset/train/traffic.csv`, `dataset/train/schedule.csv`, `dataset/validate/traffic.csv`, `dataset/validate/schedule_plan.csv`, `dataset/validate/points.csv`. Они нужны для запуска сразу после клонирования. Другие исходные данные, веса, секреты, локальные пути и журналы GPS в Git не добавлять. Модель распространяется отдельным файлом GitHub Release, параметры загрузки — config/model-release.json.

Признаки доступны только на момент прогноза. Не использовать будущие фактические прибытия из расписания и не заменять неизвестный прогноз нулём. После изменений проверить затронутые тесты и запуск Docker.
